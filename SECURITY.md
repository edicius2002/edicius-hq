# Security policy

## Reporting a vulnerability

Use GitHub's [private vulnerability reporting](../../security/advisories/new) for this
repository, not a public issue. That opens a private advisory only the maintainer can see
until it is resolved.

This is a single-maintainer project, not a company with a security team. There is no bug
bounty and no guaranteed response time — reports are handled as soon as the maintainer sees
them.

## Dependency updates

Dependabot is on for both ecosystems in this repo (npm and pip), with version updates and
security updates enabled. Security advisories on transitive dependencies open a PR
automatically; they do not wait for the weekly version-update run.
