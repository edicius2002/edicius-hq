# USD/PEN Dashboard gadget

## Accepted scope

The owner requested implementation in a separate branch after validating sources.
Ship a compact Dashboard gadget showing each source's buy and sell prices and its
own history. Provider acquisition belongs to the Raspberry Pi (ADR 0004); the
authenticated browser reads Supabase. All product text is English.

Sources: Kambista, Tu Cambista, Securex, Cambio Seguro, DollarHouse, Rextie,
TKambio, plus BCRP interbank and SBS daily references published through BCRP.
SUNAT and Cuanto Esta el Dolar are not implemented: validation did not establish
a usable authorized public collection route. No invented data or silent source
substitution. Commercial history starts when collection starts. Official history
can be backfilled from 1997, with missing days left missing.

## Data contract

`fx_observations` contains owner_id, source, observed_at (UTC acquisition time),
effective_at (UTC point time; commercial acquisition time, reference date at Lima
midnight), buy and sell (positive numeric PEN/USD, buy <= sell), and context
(small allowlisted JSON object, not a raw upstream payload). Primary key:
owner_id, source, effective_at, observed_at. Stable slugs: kambista, tu-cambista,
securex, cambio-seguro, dollarhouse, rextie, tkambio, bcrp, sbs.

Owner RLS and read RPCs enforce the existing edicius_owners allowlist.
`read_fx_latest()` returns a JSON array with the newest effective observation per
source (latest acquisition wins revisions). `read_fx_history(p_source text,
p_range text)` returns `{points: [...], aggregation: 'observations' | 'daily'}`.
Ranges are 1D, 7D, 1M, 1Y, ALL. 1D/7D preserve commercial captures; longer
ranges retain the last capture of each Lima calendar day; references always
retain the latest revision per effective day. Filter by database current time,
reject unknown inputs, and return JSON rather than a rowset subject to the REST
row limit. Points use the observation fields above. Index owner/source/time reads.
No browser writes, no service secret in frontend, no anonymous reads.

## Collector

Use httpx and Python standard library, without a browser. Fetch independent
sources with bounded timeouts and response sizes, isolate failures and validate
finite positive rates. Standard quotes only; exclude coupons and preferential
tiers. Rextie is a non-committing USD 1,000 simulation, disclosed in context.
Do not preserve cookies, tokens, internal admin fields, or full response bodies.

Use a process lock and a durable local SQLite outbox: append observations before
cloud writes, replay after outages, acknowledge only successful idempotent
upserts. A cloud outage must not prevent provider acquisition. Store next-due
times durably. Commercial cadence 5 minutes; references 4 hours and reconcile
the last 14 days. On 403 stop that source for 6 hours; on 429 respect Retry-After
with bounded delay; other failures back off. No challenge bypass. Track fx runs
using collector_runs when Supabase is reachable, including partial failures.

CLI supports one collection pass, a source subset, no-write dry run, and explicit
BCRP historical backfill by bounded yearly requests. Restarting or replaying
does not create duplicates. Outbox/state live under the existing Pi data root.

## Dashboard

Place USD/PEN above Codex resets. Match the warm dark Dashboard surfaces, cream
borders, compact mono type, restrained green buy and peach sell accents. Show
both columns at all times, clarify Buy = source buys your USD / Sell = source
sells you USD. Highest fresh commercial buy and lowest fresh commercial sell
are marked independently; references and stale quotes are excluded. Display
source age and distinguish stale, no capture, and load failure. Preserve cached
data on a refresh error. Commercial stale threshold 15 minutes; references
consider both a 12-hour capture age and a 7-day effective-date age.

A selectable source table drives a two-line buy/sell chart. Filters: All, Online,
References. Range controls: 1D, 7D, 1M, 1Y, All. Persist selected source/range and
favorites locally; favorites sort first without hiding other sources. Include
an expanded chart view. Stack table and chart on phones with no horizontal page
overflow. Hover, touch, and keyboard expose point time and both prices. Separate
source capture time from official effective date. Disclose daily aggregation
and data gaps. Loading, empty, one-point, stale, and error states are usable.
Poll Supabase only; refresh never scrapes providers. Source links are registry
constants. Display 3-4 decimals without altering stored precision.
