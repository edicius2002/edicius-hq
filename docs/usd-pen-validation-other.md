# Validación de fuentes comerciales adicionales USD/PEN

Validación puntual: **29 de septiembre de 2026, 16:45–17:05 UTC**. Pruebas HTTP desde Windows con Python urllib, sin login, evasión de bloqueos ni operaciones financieras. Los precios son evidencia de extracción; no son una oferta vigente. La comprobación desde Raspberry Pi se documenta en el informe principal. No se implementó ningún colector.

## Cotizador público Inka / Chaski: solicitud reproducible

1. GET de la raíz del mismo dominio con una sesión que conserve cookies públicas.
2. Leer `<meta name="csrf-token" content="…">` de esa respuesta. Es un token anónimo del formulario, no una cuenta autenticada.
3. POST `/convert` con JSON `{"amount":1000,"currency":"PEN","type":"buy","credits":0}` y cabeceras `Content-Type: application/json`, `Accept: application/json`, `X-Requested-With: XMLHttpRequest`, `X-CSRF-TOKEN: <token>`.
4. Leer `fxBaseSale` (compra normalizada), `fxBaseBuy` (venta normalizada), y mantener separadas posibles tasas por monto `fxBaseSaleUp` / `fxBaseBuyUp`. No se enviaron cupones ni se registró operación.

La respuesta proporciona `fxBaseAmountUp`: en Inka `1000 / 3.449 = 289.93911278631487 USD`; en Chaski `1000 / 3.454 = 289.51939779965255 USD`. Esto verifica el sentido de la venta. `coupon` fue `null`. No se probó todo el espacio de montos, bancos o promociones, ni estabilidad durante varios días. El componente de Inka/Chaski y sus cálculos están en los scripts públicos enlazados por cada portada.

## Alcance del histórico y criterio de implementación

No se validó un archivo descargable de compra/venta por casa para **ninguna** de las fuentes comerciales de esta nota. El histórico propio empieza con capturas autorizadas. El `createdAt` de Kambio permite conservar hora de publicación junto a hora de captura; para Dichikash, Inka y Chaski se conoce sólo captura. El timestamp de la comparación de Mercado Cambiario pertenece al comparador, no demuestra frescura de cada empresa.

Cuatro fuentes tienen extracción directa numérica demostrada: **Kambio, Dichikash, Inka y Chaski**. Esto no equivale a cuatro integraciones listas para producción: faltan resolución de condiciones donde corresponda y breve observación de cambios/errores. Las demás quedan explícitamente bloqueadas, sin cotizador validado, o fuera de la categoría por ser cripto.
